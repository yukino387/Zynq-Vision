检测工作台改版

依据 design-system.md Zynq-7020 · 领航者 V3.9 数据为真实遥测

不改你们的 brief，改的是它下面没兑现的部分。三处硬伤：主强调色与信息色同值、导航按数据实体而不是按角色和流程分、判定被压在一堆等重卡片里。下面每一处都给了可直接落地的替代。

三处问题

证据来自 tokens.css 与实际截图

主强调色没有语义

design-system.md 写的是「Deep Forest Green 为主强调」「Blue 留给处理信息」，但 token 里两个名字指向同一个蓝色值，主操作按钮和「处理中」状态共用一个颜色，强调层塌掉了。

--forest
#165dff
--blue
#165dff

两个 token 完全相同，这是整页只有一种蓝的原因。

导航按实体，不按角色

六个主导航是数据模型的名字。但操作工要的是「开始检测」，管理员要的是「这批样本审完去训练」，工程师要的是「训练任务跑完没」。三个角色登录后看到同一个菜单。

检测工作台检测记录数据管理模型管理设备管理系统管理

角色已经有了（ADMIN / ENGINEER / OPERATOR），只是没有用在导航上。

判定和一排数字等重

工作台上「当前检测」只是一个右侧小面板，和「设备连接」「推理耗时」「检测频率」「实际模型」四张同规格卡片并列。操作工一眼要看的是这一件过没过，现在它是最弱的一环。

设备连接推理耗时检测频率实际模型

另外那四个数字来自模拟设备，卡片本身没标来源。

    配色怎么改

    一行改动，语义立刻分开
    语义现在改后用在哪
    主强调--forest #165dff--forest 深森林绿主操作按钮、当前导航项、在线状态
    处理信息--blue #165dff--info 钢蓝进行中、排队中、部署中
    待复核--amber #b57600--amber 不变待复核判定、待审核样本
    故障--red #d03050--fault 橙红不合格、设备离线、错误码
    合格--green #00875a并入 --forest合格、已批准、已同步

    现在主强调和「处理信息」撞色，是因为两套色板各抓了一点拼在一起。#165dff 是 Arco 的主色，#d03050 是 Naive UI 的 error 色。改后强调色回到 design-system.md 写的森林绿，蓝色只留给进行中的状态，五个语义各自可辨。

# 可复制提示词

将方括号内容替换后交给任意支持文件阅读的助手；先用 plan.md 填条件。

```text
任务：[仅离线复算/设计新板测]。数据：[CSV路径]；条件：[测量计划路径]。
基线条件名：[baseline]；候选条件名：[candidate]；阶段：[phase]。
先检查输入、权重、图、量化语义和输出是否可比，列出计时起止及未包含成本。
核对每输入、每轮和每条件的样本数与缺失，不删除原始异常样本。
分别报告逐输入中位数、合并中位比、各输入中位耗时等权平均的比值。
区分卷积、全部命令、完整推理和端到端吞吐；若数据只支持某一层级，只报告该层级。
不要把 NEON 微内核外推称作整网实测，不把同轮重复当跨板独立样本。
输出：数据完整性、主结果、判断边界、需要补充的证据。仅离线任务不得访问设备。
```

# 采集计划模板

复制本文件填写，未确认字段保留“未确认”，不要默认为历史值。

| 字段 | 填写内容 |
|---|---|
| 设备与工具 | 型号、CPU/PL 时钟、编译器/工具版本 |
| 产物身份 | 源码版本、二进制/bitstream/权重 SHA256 |
| 数值任务 | 输入及哈希、图、dtype、布局、输出比较方法 |
| 基线/候选 | 条件名、线程/亲和性、编译选项、向量化证据 |
| 运行环境 | governor、采集、显示、DMA、后台服务 |
| 计时边界 | 开始/结束位置；配置、复制、等待等计入项 |
| 试验设计 | 预热、输入、轮次、交错顺序、重复数和种子 |
| 异常规则 | 超时、缺失、错误输出的记录方法，不按结果筛选 |
| 恢复条件 | 原运行状态、恢复动作与验证；仅新板测填写 |
| 统计口径 | 主估计量、输入权重、分组/重采样单位 |

# 来源、失败观察与验证效果

来源：附带 [2026-10-17 原验收文档](../evidence/model_review_20261017.md)。文中的“当前包不通过”、量化常量、命令数和验收门槛均针对当时的牛奶模型，不是今天的模型状态或通用标准。

失败观察：图与权重形状相同，仍存在 concat 原地分支尺度不一致、下游 bias/乘移依赖、输出尺度和预处理不一致。只看普通逻辑参考对拍通过，不能说明板端布局参考也正确。

已记录效果：文档记载直接适配会出现约 ±13 LSB 偏差；临时调整隐层尺度、下游 bias/乘移及输出尺度后，分数最大差 0.0023、框差 1–4 px。这是历史文档中的观察，本包未包含该试验黄金张量或重跑模型，不能独立复现这些具体数值。

可迁移方法：先写清契约，逐阶段找首次差异；把布局、量化和后处理分别核对。提供 contract.md 和 prompt.md，不绑定原模型常量。比较工具可独立运行，合成正确/错误/长度样例本次实际测试；它不生成黄金数据，不替代留出集精度或板测。

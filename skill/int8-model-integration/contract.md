# 整数量化与布局契约模板

| 契约项 | 填写内容 |
|---|---|
| 当前实现 | 图/打包器/整数参考版本及哈希 |
| 文件格式 | magic、版本、字节序、CRC/SHA 覆盖、清单 |
| 输入 | shape、通道、预处理顺序、尺度/零点、布局、stride |
| 逐层参数 | 名称、shape、算子、激活、权重顺序和 tile |
| 量化 | per-channel scale、bias scale、乘移、舍入、饱和、负半轴 |
| 安全范围 | 累加上界及中间类型；是否可能溢出 |
| concat | 分支角色、原地关系、目标尺度、重定标位置、下游依赖 |
| 输出/后处理 | shape、尺度、anchor、类别语义、坐标映射 |
| golden | 原输入与生成方法、阶段输出、参考实现独立性 |
| 判断 | 首次差异、数量、最大误差；缺失项不算通过 |

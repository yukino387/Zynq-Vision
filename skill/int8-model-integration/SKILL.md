# INT8 固定图模型接入

适用于训练包到嵌入式整数推理的移植，以及同图换权重的数值排查。不限于本队网络，但需当前硬件、打包器与整数算子契约。不适用于只检查浮点精度或普通训练。

## 使用

复制 [contract.md](contract.md)，按当前实现填写，再使用 [prompt.md](prompt.md)。先离线校验结构、布局和整数语义，只有任务包含安装时才上板。

从包根目录调用已有标准库比较工具：

```text
python skill/fpga-accelerator-workflow/scripts/verify_tensor.py --reference golden.bin --actual actual.bin --dtype int8 --count 1617
```

替换路径及 count；count 是逻辑元素数，不是任意文件字节数。支持 int8/uint8/int16，int16 小端。退出码 0 一致、1 数值不同、2 输入/长度错误；必须先按契约去掉 padding，工具不会猜布局或生成参考。

## 排查流程

1. 文件完整性：清单、字节数、包头、CRC、SHA256；分清整个包和 payload 的摘要。
2. 固定图：逐层 shape/dtype/算子参数/顺序；分清逻辑布局、行跨度、tile 权重打包，元素数相同不证明布局一致。
3. 输入：RGB565 解码、通道/灰度、缩放裁剪、旋转、取整和饱和逐像素一致；相同照片不等于相同 INT8 输入。
4. 量化：输入/输出/每通道权重尺度、零点、bias 尺度、舍入、负半轴、乘移和累加上界。bias 一般对应 input_scale × weight_scale；修改输入尺度要追踪 bias 和乘移。
5. concat：分支角色、目标尺度、原地复用、实际重定标位置。发现不一致要追踪下游，不能只改输出尺度掩盖误差。
6. 输出：head 尺度、anchor、类别槽位、坐标与产品规则；未训练的占位类不当作有效类。
7. 对独立整数参考和布局参考逐阶段对拍，先定位首次偏差；保留有检出、无检出及边界输入。真实业务精度和整数一致性分别报告。

## 失效条件与效果

缺失尺度/舍入/布局契约或参考不独立时，不能声明数值正确。非对称量化、浮点容差和其他算子需扩展契约；比较脚本不验证溢出或模型精度。旧包标准的尺寸、阈值、版本不能当作新包要求。

# 部署记录模板

| 项目 | 待填写内容 |
|---|---|
| 任务范围 | 要改变的功能、已授权动作 |
| 设备契约 | SoC、系统、地址、连接方法、服务管理入口 |
| 启动与存储 | RAM/QSPI/SD/eMMC，正式路径与启动设置 |
| 原状态 | 服务、模型/产品/批次、调频、UDP 接收方 |
| 候选身份 | 源码版本、构建命令、文件和 SHA256 |
| 备份/回退 | 备份路径、原文件哈希、回退步骤与触发条件 |
| RAM 结果 | 输出、错误、UI 场景及进程状态 |
| 存储检查 | 内核 I/O、fsync、读回结果；未测写未测 |
| 安装后 | 设备/交付文件哈希、启动设置、功能 |
| 恢复验证 | 额外改变项的恢复结果 |
| 启动验证等级 | 进程重启/软件复位/断电冷启动，时间和结果 |

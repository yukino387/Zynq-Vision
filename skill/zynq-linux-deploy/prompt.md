# 可复制提示词

```text
任务：[分析/试运行/部署]，设备契约和备份计划见 [deployment.md路径]。
先查询现场状态，区分 Linux 启动与裸机 JTAG；不沿用旧模型、产品或运行状态。
只构建受影响软件，在 RAM 验证候选和恢复路径，再决定是否满足正式安装条件。
UI 问题同时验证默认页、状态延迟到达、切换、退出重进和进程重启。
写正式介质前检查 I/O 与 fsync/读回；出现错误停止写盘并保留证据。
安装后核对候选/设备/交付副本身份，恢复额外改变的状态。
输出逐级结果：RAM、持久文件、进程重启、软件复位、冷启动；未做的写未验证。
不得把本案例中的地址、服务名、SLCR 寄存器或默认页面当作当前设备配置。
```

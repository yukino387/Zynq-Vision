# 从工程证据绘制架构图

适用于系统/IP 概览和完整层级图册，可迁移到其他 FPGA 工程。提供提示词与审查模板，不附带绑定本队网表的自动制图程序，也不声称为通用 Vivado 提取器。

## 使用方法

填 [inventory.md](inventory.md)，把 [prompt.md](prompt.md) 与当前工程证据交给助手。只有需要的层级才展开；概览任务不默认输出完整图册。读取工程不启动新综合或上板。

1. 记录 BD、RTL/HLS、IP 导出、DCP 的身份和版本关系；不同版本不能拼为同一当前实现。
2. BD 查 cells、接口/普通网络、外部端口、地址、时钟复位；源码查内部控制与数据关系；DCP 查实现层级和时钟。未知黑盒内部不根据名字推造。
3. 用稳定 ID 建统一的模块/端点/网络数据，让图和连接表同源。标方向、协议、位宽、主从及跨时钟域。
4. 系统概览、内部逻辑、HLS 调用、实现网表分视图；函数调用不证明硬件并行。
5. 用户要求完整时先定义集合、过滤规则及计数单位（向量/bit/网络），再检查遗漏、重复、悬空、未归属端点。分层细图与连接表共同覆盖，不把所有线压进概览。
6. 渲染后检查字体、裁切、箭头、交叉、分页和最密集页面；程序覆盖不能替代视觉检查。按需要交付 SVG/PNG/PDF 和可检索表。

## 失效条件与效果

源码与实现身份不一致、缺少端点或覆盖集合未定义时，不能宣称完整。真实工具截图与重绘示意分别标注；覆盖统计只能证明定义集合，不证明黑盒内部完整。大网表仍需针对工具版本写提取适配并实际验证。

本队案例在定义的顶层网络、内部网络及 CNN 端口集合内完成覆盖检查，未形成跨工程效果试验，见 [case.md](case.md) 和附带历史验证 JSON。

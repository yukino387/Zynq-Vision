# 实现、诊断与发布

## 接口与模型契约

读取作者实现和当前生成驱动，不凭历史名称推断。对照 IP/BASEADDR、函数、寄存器含义、指针位宽、start/done、cache 管理和 DDR 归属。

每个算子记录 C×H×W、kernel/stride/padding、激活、权重数量、布局、物理行宽、偏移和分配容量。拼接、split、分支复用按地址区间检查，避免指针正确而容量不足。

`round(float*512)` 是特定 INT16 工程格式，不是所有量化模型标准。INT8 量化适配须确认 signed/unsigned、zero point、逐层/通道 scale、bias/累加位宽、负数舍入、饱和和激活。INT8 输入不等于 8 位累加。RGB565、网络 RGB/灰度、归一化和 resize 分别确认。

## 逐级验证

按任务需要：算子 → 单层 → 多层模块 → backbone → 完整 forward → 真实权重 → 固定真实图片 → 摄像头/传输。已有阶段通过时不重做全套，只检查本次受影响边界。

临时测试独立，优先复用 PASS 输入/权重；量化适配时建立匹配的整数参考。定位错误时检查中间阶段，再检查最终张量、tile 尾部、非整并行度通道、负数、padding 和原地写回风险。

PC 权重加载通过不证明板卡获得正确权重；编译通过不证明初始化/下载通过。标注测试发生在主机、ARM 还是 FPGA。

## 耗时诊断

固定权重、输入、时钟、ELF 与模式，测各硬件调用、准备、传输和帧周期。短测重复少量次数，报告中位数/范围，不宣称长期稳定。

计数器不便低风险加入时，用 PS 定时器包围调用并做同形状控制实验；注明启动设置、cache flush、等待是否计入。

| 对照 | 支持的判断 | 不可直接推出 |
|---|---|---|
| 正常 vs 关闭输出 | 当前输出阶段增量 | 纯 MAC 时间、旧版输出成本 |
| 同 shape 首次 vs 重复权重 | 经确认的缓存命中效果 | 缓存一定跨调用保留 |
| cache/CI 边界扫描 | 缓存边界与搬运关联 | CI 增加的所有时间都属 cache miss |
| 大小图固定 CI/CO | 启动、搬运和 tile 利用率趋势 | 图像缩小必按面积提速 |
| 开/关预览 | 当前通信负载差异 | 摄像头直接占卷积 DSP |

MAC/峰值仅是理论下界，说明计数口径、有效 lane、频率。灰度只减少首层输入通道相关 MAC，后续 feature 通道由结构指定；INT8 只有配套 DSP 打包/数据通路变化才能证明资源收益。

并发可提高吞吐而仍有单帧延迟。只有独立资源和无冲突缓冲才能重叠采集、准备、推理和发送；异步 API 不消除层间依赖。

## 最小候选

loader 瓶颈查银行/端口、burst、布局、cache；输出瓶颈查 requant/打包/store 串行；池化区分比较与短段访存。最终 II/资源由报告确认，不只看 pragma。

优先改已定位通路，保留网络/引擎。多引擎、融合、feature cache、分辨率和模型更换属于另一级范围，需测量和目标支持；不要增加峰值同时制造 DDR/BRAM/时序瓶颈。

诊断和正式候选分开命名，记录源码/入口/日志。HLS 估计和 post-route 实际资源分列，BRAM18K/36K/Tile 单位明确；HLS clock 不等于实际时钟。

## 发布与回退

检查最终 setup/hold、未约束路径和设计特有 CDC/bus-skew、器件实际 DSP/BRAM/LUT/FF。一次上板运行不能掩盖时序失败。

核验下载、权重、受影响完整链路、日志 PASS/错误数和黄金输出，不只看 XSDB 返回码。按授权短测端到端并暂停/恢复板卡。

干净正式候选通过后才更新 bit/XSA/HLS IP/软件组合，记录版本/hash，再通过正式入口核验；错误候选保留失败证据，不计为成果。

报告列条件、改动、正确性、各层/整网耗时、FPS、资源/时序、局限和原始证据路径。按授权保存 Git，不混入生成物和无关修改。

# 边缘视觉质检系统：技术基线与验证范围

文档版本：ENG-SPEC-2026-V1.1；更新日期：2026-10-27。实际仓库：`C:/00_workplace/fpga/cnn_accelerator`。本文件记录当前可核对的工程基线；本次为离线文档与证据核查，未操作板卡。

## 1. 系统与任务

系统由PC平台、手机App和Zynq终端组成，以牛奶包装贴片模拟缺陷为主案例，瓶盖数量与液位为扩展案例。平台管理采样、标注、数据快照、模型、产品规则、批次及复核；App用于现场采样、操作与复核。当前工程是可运行原型，独立精度、长期可靠性和实际分选能力未验收。

固定图支持224×224 RGB三通道或灰度单通道INT8输入。33算子包含21卷积、8重定标、3最大池化和1上采样。输出头为33×7×7与33×14×14，去除补齐后8,085字节。模型须满足固定命令模板；通用性不等于支持任意网络。液位另含ARM红标签定位、裁窗与行测量，合格带85.0～102.9，当前专用包SHA前缀3aca8253。

## 2. 当前硬件与数据通路

| 项目 | 基线 |
|---|---|
| 硬件 | 领航者V3.9，Zynq-7020，ATK-MC5640 V1.2 |
| 构建器件 | xc7z020clg400-2 |
| 采集 | OV5640 DVP→打包/异步FIFO→AXI DMA→DDR；416×416 RGB565 |
| 推理 | PS预处理/调度→PL固定算子→PS解码、过滤与任务判定 |
| PL计算 | 125 MHz，48输出×8输入通道并行，384个INT8乘积/有效发射 |
| DSP映射 | 192个双INT8乘积DSP操作；整设计217/220 DSP |
| 内存接口 | 4组特征与4组权重AXI bundle分组接入HP0～HP3，共享PS DDR |
| 数据类型 | INT8权重/激活、INT32累加、INT64重定标；饱和[-127,127] |
| 特征布局 | 64位打包，行宽7/14/28/56/112/224补齐8/16/32/64/128/256 |

当前size>14行输入路径将AXI读取与字节解包拆成DATAFLOW任务，用深16、宽64位SRL FIFO连接；原通道组装载/计算乒乓继续保留。核内组间交叠不等于整网所有算子同时执行。

## 3. Linux运行时与显示

当前终端运行Linux 6.6.159，engine、panel、manager协作；模型、产品与生产批次分别管理。本地运行及平台同步路径见技术正文。裸机`camera_live`、lwIP UDP和WinUI调试链仍为独立开发入口，不能将其地址空间、OTA或BSP约定直接套用到当前Linux。

显示为RGB565双缓冲，自定义1280×720、1650×750总时序，像素30.9375 MHz、串行154.6875 MHz，实际扫描25 Hz；不是CTA标准720p25。面板显示/状态与预览轮询上限25 Hz。移除1,843,200字节shadow副本，翻页后同步脏区。有效像素载荷预算110.592→46.080 MB/s，不代表DDR总流量实测。

## 5. 两轮优化与性能

| 同模型固定输入试验 | 21卷积 ms | 33命令 ms |
|---|---:|---:|
| 行重叠A/B/A基线→优化 | 56.915904→54.247131 | 61.985364→59.324442 |
| 行重叠持久启动后复测 | 54.242113 | 59.313562 |
| 显示60→25 Hz同次对照 | 54.253900→52.567852 | 59.321953→57.633496 |
| 25 Hz固化软件复位后 | 52.543651 | 57.607381 |

卷积局部改善分别为4.689%与3.108%。A/B/A的A合并24次，其余各12次普通轮询；另有预热和插桩样本不入性能统计。按命令setup_ns+start_write_ns+wait_ns累加后取前向中位数。CPU1、performance、面板暂停而显示DMA活动。输出一致性为归档试验结果，本轮只复算现存CSV/stdout。

当前版本关闭采集和显示后，10月27日随机交错主试验为ARM 36次、PL 612次，另66次编译敏感性试验，合计714次。模型CAPS-RGB-v1，SHA 2658b41a…；三种照片内容均使用此模型。

单输入编译敏感性试验的33算子中位耗时：ARM O0标量47,195.384758 ms（6次），O3禁向量化12,011.039459 ms（6次），O3允许自动向量化12,105.349974 ms（6次），PL 56.590315 ms（48次）；对应ARM/PL中位比分别为833.98、212.25、213.91倍。O0作用于标量参考源码变体。各条件均值、范围、标准差和全部33条O0/O3/PL逐算子数据见[完整性能报告](../temporary/arm_pl_stats_20261027/report.md)。

## 6. 启动与交付身份

- Linux正式bitstream：`hardware/camera/build/terminal/system_wrapper.bit`，SHA-256 `2d18f88f7679919176049564183a55871d28c67d08f270b22e705c0848330c54`。
- 交付BOOT：`camera/terminal/build/delivery/boot/BOOT.bin`，SHA-256 `13ef13af6355e472bb06ddfad33eee44c532e001c09fe6d495f1ee16b7c9b3c0`。
- HLS源码：`hardware/hls/src/std_conv.cpp`，SHA-256 `56713764914f861a57d98f91e81ec0ccff6ed198a8d468985b589575df8bcac9`。
- 归档部署记录确认QSPI FSBL/FPGA/U-Boot→SD内核/根文件系统的软件系统复位启动；断电冷启动与长期可靠性未验收。

裸机正式入口`vitis_live/run_live.tcl`会复位PS并通过JTAG下载，不能作为Linux持久启动证据。整盘SD镜像、initramfs与rootfs压缩归档未按此次固化重打包，不能作新版工厂镜像交付。

Linux应保持SLCR解锁，但SLCR=0不能证明SD可靠。既有两次写入异常根因未定；后续离线检查和4 MiB写入/fsync/读回是限定短检。出现新I/O错误应停止写盘并保留备份。双槽OTA、掉电回滚、长期稳定性与工业高可用不得由旧裸机设计目标推定为当前Linux已验收能力。
